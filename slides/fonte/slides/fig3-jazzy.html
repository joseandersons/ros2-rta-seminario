Aqui mostrar o gráfico gravado; rodar ao vivo no final da apresentação, antes das perguntas: bash ~/ros2-rta-seminario/original/ao_vivo.sh (uns 10 s; a janela abre sozinha e desenha as callbacks enquanto rodam). É o código original dos autores (repositório boschresearch/ros2_response_time_analysis, pasta model_validation), com ajustes só de API para compilar no Jazzy; o gráfico é montado lendo os logs que o próprio código deles imprime. Tarefas: subscribers high, medium, low (amarelo), services srv_high, srv_medium, srv_low (azul) e timers 0 a 3 (vermelho), cada um ocupando 500 ms. A primeira barra curta do high (300 ms) é a mensagem de aquecimento que o script dos autores manda antes da rajada, para o executor estar ocupado quando ela chega. O srv_medium chega em ~2,3 s e só roda em ~6,8 s, igual ao artigo. O que mudou (timers esperando a janela e a ordem dentro do tipo) fica para o próximo slide. Os tempos variam um pouco a cada execução.
