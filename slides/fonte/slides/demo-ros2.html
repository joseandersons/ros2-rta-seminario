Rodar ao vivo no Ubuntu (WSL): bash ~/ros2-rta-seminario/demo/apresentar.sh robo. Leva uns 3 segundos e o gráfico abre sozinho. Antes, mostrar o código no VS Code: polling_demo.cpp, classe Robo (as três callbacks e os tempos) e a função run_robo (a parede chega em 50 ms). É a mesma cena do slide 6, com os tempos multiplicados por 100 para dar para ver: sensor 200 ms, bateria 500 ms, desviar 300 ms. Os triângulos são as chegadas. Se algo falhar, este gráfico é o resultado já gravado. Os números variam alguns milissegundos a cada execução porque o WSL não é tempo real, mas a ordem se repete.
